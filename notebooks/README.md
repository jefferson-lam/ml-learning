# Notebooks

Create one notebook per chapter or focused experiment:

```text
01-end-to-end-ml.ipynb
02-classification.ipynb
03-training-models.ipynb
```

Begin each notebook with:

1. The question being tested.
2. Your prediction.
3. The smallest experiment that can answer it.
4. A short conclusion in your own words.

Move code that you expect to reuse or test into `src/ml_learning/`.
